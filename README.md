# 🎓 Student CGPA Calculator

A simple and user-friendly Student CGPA Calculator built using Python and Streamlit.

This application allows students to calculate their semester CGPA by entering their subjects, credit hours, and grades.

## 🚀 Live Demo

👉 Open the live CGPA Calculator:
https://t45f4ijpjswnjjukrb2q.streamlit.app/

## ✨ Features

- 📚 Add multiple subjects
- 📝 Enter subject names
- 🎯 Select grades
- ⏱️ Enter credit hours
- 🧮 Automatically calculate semester CGPA
- 📊 Display total subjects
- 📊 Display total credit hours
- ⭐ Display total quality points
- 🔄 Reset calculator
- 🌐 Access the calculator through a web browser

## 🛠️ Technologies Used

- Python
- Streamlit
- GitHub
- Streamlit Community Cloud

## 🧮 CGPA Calculation

The application calculates CGPA using:

**CGPA = Total Quality Points ÷ Total Credit Hours**

Quality points are calculated using:

**Quality Points = Grade Point × Credit Hours**
